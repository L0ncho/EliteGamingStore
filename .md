## Plan de acción (solo CSS + viewport; sin tocar textos ni etiquetas)

Archivo a editar: `Alonso_PFY2201_CSS_Semana2.css`. Se reutiliza el mismo archivo para no romper el `<link>` existente.

### Paso 1 — Flexbox exclusivo en nav y footer

- **Conservar** Flexbox en `.menu-principal ul` (`display: flex`, `justify-content: center`, `gap`). Opcional: `display: flex` también en `.menu-principal` si hace falta alinear el `ul`.
- **Conservar** Flexbox en `.redes-sociales` (enlaces del footer en fila).
- **Quitar** Flexbox de `.lista-productos` y la propiedad `flex: 1 1 300px` de `.producto` (esa es la migración a Grid).

### Paso 2 — CSS Grid en `.lista-productos`

Reemplazar el bloque actual:

```css
.lista-productos {
    display: flex;
    flex-wrap: wrap;
    gap: 1.5rem;
}
.producto { flex: 1 1 300px; /* se elimina flex */ }
```

por Grid de escritorio:

```css
.lista-productos {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 1.5rem;
    margin-top: 1.5rem;
}
```

`.producto` mantiene borde, padding, sombra, `nth-child` y `:hover`; solo pierde `flex`.

### Paso 3 — Tres media queries (reemplazar `@media (max-width: 600px)`)

| Breakpoint | Alcance | Cambios previstos |
